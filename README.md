# Элсистар — корпоративный сайт

Адаптивный сайт на HTML, CSS и JavaScript. Node.js нужен для локального сервера и предварительного рендеринга, внешних зависимостей нет.

## Запуск

```sh
npm run build
npm start
```

Открыть http://127.0.0.1:3000. Также работает встроенный просмотр WebStorm из подпапки проекта.

## Редактирование

- `index.js`: переиспользуемые компоненты, содержание страниц и интерактивность.
- `styles.css`: дизайн-система и адаптивные стили.
- `page-shell.html`: исходный HTML и сохранённые подробные технические материалы.
- `assets/*.jpg`: оптимизированные фотографии. Оригиналы PNG сохранены.
- `npm run build`: создаёт восемь HTML-страниц с текстами, метаданными и sitemap. После изменения компонентов или исходного HTML выполните сборку.

Исходные URL: `production.html`, `software.html`, `foton.html`, `support.html`, `contacts.html`, `price.html`. Дополнительно создана `about.html`. Англоязычные материалы и документация доступны на оригинальном сайте по существующим ссылкам.

## Проверка

```sh
npm run check
python3 scripts/validate.py
```

Проверяются синтаксис JavaScript, наличие локальных страниц, изображений и якорей, уникальность ID, H1, alt и размеры изображений, назначение форм. В Safari вручную проверены главный экран, переход в каталог, фильтрация, открытие/закрытие карточки решения, мобильный первый экран и меню при ширине 393 px в режиме отзывчивого дизайна. HTTP-проверка всех восьми страниц и ресурсов прошла успешно.

## Обратная связь

Backend доставки писем и SMTP-доступ в исходном проекте отсутствуют. Форма валидирует поля и подготавливает письмо через `mailto:`. Пользователь самостоятельно отправляет его из почтового приложения. Сообщение об автоматической отправке не показывается. Для отправки прямо с сайта потребуется подключить почтовый сервис или существующий API компании.

## Материалы и ограничения

Факты о компании, контакты и описание «Мегаполиса» сверены с elsystar.com. Технические описания контроллеров сохранены из исходного проекта. Фото контроллеров и иллюстрация диспетчерского центра взяты из `assets`; концептуальная схема явно подписана. Новые сертификаты, клиенты, количественные достижения и технические характеристики не добавлялись.

Реальные полевые Core Web Vitals требуют замера на опубликованном сайте. Проверку на физических мобильных устройствах и полноценный аудит консоли/Lighthouse в этой среде выполнить не удалось. Использованы системные шрифты, сжатые изображения, заданные размеры, lazy loading и prefers-reduced-motion.

Для публикации достаточно HTML-страниц, `index.js`, `styles.css`, используемых JPG в `assets`, `robots.txt` и `sitemap.xml`. Остальные файлы проекта публиковать не требуется. Локальный сервер раздаёт только публичные страницы и ресурсы.
